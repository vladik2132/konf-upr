\## 🚀 1. Общее описание

Настоящий проект представляет собой консольный \*\*эмулятор командной оболочки операционной системы (Этап 1: REPL)\*\*, разработанный в рамках выполнения практических работ по дисциплине «Конфигурационное управление» (Вариант №13). 



Программа максимально точно имитирует поведение командной строки UNIX-подобной ОС, обеспечивая непрерывный интерактивный диалог с пользователем («Read-Eval-Print Loop»)\[cite: 1]. Основной упор сделан на корректную обработку пользовательского ввода, парсинг аргументов и стабильность работы при возникновении нештатных ситуаций.

\## ⚙️ 2. Системные требования

Для запуска эмулятора на вашем компьютере должно быть установлено:

\* \*\*Операционная система:\*\* Linux, macOS или Windows (с поддержкой Python).

\* \*\*Интерпретатор:\*\* Python версии \*\*3.8\*\* или выше.

\* Дополнительные сторонние библиотеки устанавливать \*\*не требуется\*\* (используются только встроенные модули `os` и `socket`).

\## 🛠️ 3. Описание всех функций и настроек



Эмулятор реализует следующие базовые компоненты первого этапа\[cite: 1]:

\* \*\*Динамическое приглашение ввода (Prompt):\*\* Формируется автоматически на основе текущих параметров операционной системы в классическом UNIX-формате: `username@hostname:\~$`\[cite: 1].

\* \*\*Простой парсер команд:\*\* Считывает строку, удаляет лишние пробелы по краям и разбивает её с помощью метода разделения по пробелам на составляющие: первое слово интерпретируется как команда (`cmd`), а последующие элементы — как список аргументов (`args`)\[cite: 1].

\* \*\*Команды-заглушки:\*\*

&#x20; \* `ls` — имитирует вывод содержимого директории, выводя название команды и переданные аргументы\[cite: 1].

&#x20; \* `cd` — имитирует смену рабочей директории, выводя название команды и аргументы\[cite: 1].

\* \*\*Команда управления сеансом:\*\*

&#x20; \* `exit` — корректно завершает работу интерактивного цикла эмулятора\[cite: 1].

\* \*\*Обработка ошибок:\*\*

&#x20; \* Пустой ввод игнорируется (программа запрашивает команду заново).

&#x20; \* При вводе несуществующей команды приложение выводит уведомление об ошибке, но \*\*не падает\*\* и продолжает работу в штатном режиме.
